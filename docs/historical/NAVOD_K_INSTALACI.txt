INSTALACE VE WINDOWS POWERSHELLU
1. Zastavte Flask server klávesami Ctrl+C.
2. Ujistěte se, že jste ve správné větvi (git branch --show-current).
3. Doporučeno: před přepsáním mít čistý git status nebo vlastní commit / zálohu.
4. Rozbalte ZIP do kořenové složky projektu:
   Expand-Archive -Path "$env:USERPROFILE\Downloads\Fact_or_Watt_UI_nav_a_logo_content_improvements.zip" -DestinationPath . -Force
5. Spusťte:
   uv run pytest -q
   uv run flask --app src/index.py run --debug
6. Vyzkoušejte živý režim, uložená data a tlačítko ukázkového reportu.
7. git diff --check; git diff --stat; git status --short
8. Až po ověření commitnout pouze změněné frontendové soubory.

POZNÁMKA: Nic v backendu, API kontraktech ani výpočtech se tímto balíčkem nemění.
